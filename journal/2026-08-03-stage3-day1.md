## 배운 것

## 막힌 점 / 에러

- `isEmpty()`에서 `this.items.length`를 `this.isEmpty.length`로 오타 → **함수도 객체라서 `.length`(선언된 파라미터 개수 = 0)를 갖고 있어** 컴파일 에러 없이 항상 true 반환. `number == number`라 타입도 성립해 TS가 못 잡음 — "컴파일 통과 ≠ 정답", 테스트가 잡는 영역.
- `peek()`에서 `if (this.items[i])`로 **truthy 검사**를 하면 스택에 0, '', false 같은 falsy 값이 들었을 때 "비어 있다"고 오판 → 존재 검사가 필요하면 그냥 인덱스 접근(범위 밖이면 자연히 undefined). 테스트가 1,2,3만 써서 안 걸렸던 잠복 버그.
