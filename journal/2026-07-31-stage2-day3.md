## 배운 것

- 상속과 조합에 대해서 명확하게 배웠음. 클래스를 상속 받는건 is-a 와 has-a 인터페이스로 조합하는 것
- 상속이 만드는 강한 결합과 fragile base class 문제를 배웠음. 상속은 부모의 모든걸 다 받고, 부모가 바뀌면 자식이 흔들림. 교체가 어려움. 다중 상속이 불가함.
- 부모 클래스를 안전하게 수정했지만 부모 클래스를 상속 받는 자식 클래스에 영향이 갈 수 잇음.
- 조합은 필요한 기능을 가지고 있는 필드로 가지고 위임. 조합(인터페이스)을 활용하게 되면 쉽게 교체 가능하며, 테스트 가능 하다.
- 클래스와 조합을 언제 사용해야 하냐, A는 B다가 자연스러우면 클래스, A는 B를 가진다/사용한다/쓴다 가 자연스러우면 조합 사용
- 인터페이스의 경우 여러개의 조합을 사용할 수 있음.
