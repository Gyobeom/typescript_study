## 배운 것

- 팩토리 메서드 = "인스턴스를 얻는 통로" 역할 개념, static = 클래스 소속이라는 문법 개념 — 서로 다른 축이며 겹치는 부분이 "정적 팩토리 메서드"
- 자기 클래스의 **최초** 인스턴스를 만드는 팩토리는 static이 필연 (인스턴스 메서드는 이미 인스턴스가 있어야 호출 가능 — 닭과 달걀)
- 생성자 대신 팩토리를 쓰는 이유: 생성 의도를 담은 이름(`fromString`), 생성 전 파싱·검증, 반드시 새 인스턴스가 아니어도 됨(캐싱 가능)
- 인스턴스 메서드로 인스턴스를 반환하는 경우는 역할이 다름: 파생 메서드(`p1.translate()` — day1), 상태를 품은 팩토리 객체(`factory.create()`, NestJS useFactory 계열)
